Date: 2026-10-19  
Owner: Lenticule Science / Obsmetrological Services Section  
Target: https://obsmetrologia.science.561.group  
Status: **research and interface requirements, not a deployed implementation**  
Source foundations: [Obsmetrologia](https://github.com/lenticule-science/obsmetrologia), [Page Law](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/verso/ObsmetrologiaManual/BookI/PageLaw.lean), [idea-to-Verso loop](https://github.com/lenticule-science/obsmetrologia/blob/main/lib/agency/policies/loopflow.md)

## 1. The actual job

Enable a reader to navigate **mathematically generated claim-sites**, inspect a
statement, reconstruct the warrants joining it to its generating predecessors,
and follow different modes of explanation without sacrificing source identity,
formal status or unproved obstructions. A figure should make precise mathematical
work easier, not merely produce an attractive graph.

The source program begins with the attempted failure of final relationlessness
and admits Mark, Utterance and Articulating before deriving later carriers.
The mathematics is intentionally much deeper than any keyword index or chat
summary. In particular, **L-Space refers mathematically to points of generated
Kinematic Space** where earned; it is not identified with a document vault, file
path, source URL, RDF graph, GitHub repository, browser canvas or selected
finite conventional example. Such representations can *address and describe*
these structures when a witnessed map justifies the transport.

The site should reuse the actual [L-Space](https://github.com/lenticule-science/l-space.561.group)
CAIRN/TUFTE source-selection and graph reader rather than stand up a second
source index. Source data, theory, page and user instance are different
objects; each has its original owner and rights.

## 2. Target reader journeys and conditions of satisfaction

### R1 — Follow one generated mathematical claim

Given a source-admitted claim-site, the reader can select a displayed panel
and see: exact name/IRI or qualified source address; originating Mark/Utterance/
Articulating phase and lawful predecessors; typed proposition including
hypotheses; actual proof/Blueprint/Verso carriers; revision identity; status
with positive and contrary testimony; generated downstream uses; and the
strongest legitimate *next question*. Any missing field must be explicitly
unknown, not fabricated from a title or graph location.

**Pass:** selecting the source theorem
Obsmetrologia.Articulating.reattendHead_ne_source shows its actual declaration,
the supplied Articulating hypothesis and its source file, while an adjacent
“obstruction forces unique next action” conjecture remains *frontier*.

**Fail:** both nodes have identical green “proved” styling just because they
are reachable along one diagram edge.

### R2 — Inspect the mathematical gutter, not just the edge

A focused directed edge reveals the **predicate of the transition** and the
actual warrant: exact original source, evidence/revision, relevant proof
declaration or construction, and which assumptions carry across the
transition. Different edge families are explicitly distinct:

- **generated-by**: a source-earned map from prior Articulating phase;
- **uses/dependency**: premise or declaration dependency, not itself proof;
- **recovered-as**: mathematical comparison with separately named preserved
  properties and forgotten information;
- **explained-by**: communication transport into a panel/lesson/figure,
  not a proof;
- **contradicted-by/refuted-in**: retained adverse testimony and counterexample;
- **unsettled-obligation**: missing bridge with precise falsifier/gate.

The existing graph reader must never silently turn a reified RDF statement,
source tag, support witness, map arrow or status color into an asserted theorem.

**Pass:** clicking the edge from source Articulating to an ordinary graph or
FOUR reading displays exactly which bridge is *proved*, *hypothesized* or
*absent*. The reader can navigate back to the original source without a
duplicate document graph claiming to be L-Space itself.

**Fail:** a path of source-labeled edges is labeled “proof completed.”

### R3 — Offer four full Diátaxis views from one admitted claim

The same source claim may project into:
(1) **tutorial** with a bounded reconstructible exercise and checked answer;
(2) **how-to** with source commands, dependencies and explicit failure cases;
(3) **reference** listing statements, identifiers, assumptions and proof status;
(4) **explanation** connecting phase necessity, projections and loss.

The long-scale coverage unit is **an original Blueprint claim-site**, placed
under its generating topic namespace, concept module and exact term. The
historical [Diataxis coverage chapter](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/verso/ObsmetrologiaManual/PartVI/DiataxisCoverage.lean)
already states this rule; current phase Books receive it without restoring
the superseded Part hierarchy. Coverage counts actual, working
reader routes and their quality, not empty topic folders. An existing
shared tutorial/how-to may satisfy several terms only when the exact
declarations and open obligations are navigable from each source site.

These are reader tasks, not four mathematical primitive truth states or four
separate stores. They must use the same source identity and display the same
claimed theorem status, even when their prose and illustrations differ. The
first substantive draft set is in this site's content directory, centered on
the finite four-vertex graph and separately showing where conventional
finite graph theory differs from native Mark generation.

**Pass:** switching a mode keeps the same source/claim focus, preserves an
explicitly open gutter, and gives meaningful mode-specific content.

**Fail:** a successful tutorial promotes the native metaphysical conjecture to
proved or replaces an unresolved mathlib bridge with a confidence badge.

### R4 — Paper and proof-lane navigation

A release candidate must have distinct original identities for:
a conjecture/corpus source; docket question; research record; Blueprint node;
Lean declaration; checked source commit/axiom receipt; Verso page;
conventional restatement/mathlib pinned proof when one exists; paper version;
public host/DOI receiving. A claim can have multiple *representations* and
multiple release versions, but moving between carriers never manufactures
the evidence absent in an earlier carrier.

The original [loop.mjs](https://github.com/lenticule-science/obsmetrologia/blob/main/scripts/loop.mjs)
alone advances the proof docket under entitled office and passing gate. The
site provides link and status presentation only. Frontier notes can be
editorially published under [issue #20](https://github.com/lenticule-science/obsmetrologia/issues/20)
without pretending to reach the proved Verso stage. Independently pinned
conventional Lean/mathlib verification remains a distinct extraction lane
under [issue #23](https://github.com/lenticule-science/obsmetrologia/issues/23).

**Pass:** one candidate shows its native Lean result as source-qualified,
its mathlib counterpart as “not independently checked,” and DOI as absent,
without hiding the actual working manuscript.

**Fail:** a green Blueprint node, passing web build or populated paper metadata
is misreported as an independent theorem, DOI or received publication.

### R5 — Actually usable graphical interface

The existing TUFTE directed graph and table should be two synchronized
views of *the same source-selected bounded relation page*. Focus, query,
predicate filter, pagination, browser back/forward, evidence drilldown and
authorized download must not disagree. Graph pan/zoom is helpful, but the
table, text alternative, semantic headings, focus order, and source links
must remain complete when graphics or JavaScript are disabled.

A reader can choose a mathematically meaningful view (generative phase,
claim-dependency, proof-state/frontier, or sequenced panels/gutters) using
actual typed predicates; positions in a canvas must not be asserted to be
intrinsic geometric coordinates in generated Kinematic Space. Time axes
require original dated observations; a coordinate or Lorentzian metric
requires independent, warranted mathematical/empirical input.

Support readable equations with native browser-compatible [MathML Core](https://www.w3.org/TR/mathml-core/)
where supported, a text/linear fallback, accessible labels, and copyable
source notation. Original Lean/Verso still owns verified source examples;
TUFTE presentation must not duplicate a theorem prover.

**Pass:** keyboard-only and no-script readers can answer “which source
proves this?” and “which proposed bridge remains open?” without color,
layout, pointer gestures or client-side state.

**Fail:** only a canvas can expose the contrary evidence, or an arrow's
placement is presented as causal distance or physical spacetime.

Transport must prefer native W3C [JSON-LD 1.1](https://www.w3.org/TR/json-ld11/),
[PROV-O](https://www.w3.org/TR/prov-o/),
[SHACL](https://www.w3.org/TR/shacl/) and published provider HTTP
content-negotiation where their semantics fit. The internal Sign stack's
source-defined codecs are the sole adapters into original witnessed
semiotic statements; do not introduce a site-specific opaque JSON schema,
new RDF parser, duplicate SPARQL engine, phantom 3D coordinate system or
unbounded graph traversal. A reified RDF statement does not assert its triple.
Preserve support and opposition independently, never “last write wins.”

Current TUFTE and CAIRN branches are not assumed to be released npm
dependencies; a source commit and a version string do not establish
installation. Scientific content is also subject to independent public
editorial rights and licensing decisions.

## 4. Concrete acceptance and refusal assays

1. **Exact theorem + open neighbor:** fetch the original theorem's sourced
   statement and a known open necessity bridge, render them separately and
   verify the graph/table/edge detail retains two distinct statuses.
2. **Source loss under projection:** project two distinct performed
   Articulatings sharing one head presentation. Show equal head labels but
   distinct original performed source IDs, with no fake inverse readout;
   this is the source's
   [head-only non-reconstruction theorem](https://github.com/lenticule-science/obsmetrologia/blob/main/Obsmetrologia/Articulation/Articulating.lean).
3. **Contradictory testimony:** the original CAIRN/SignGraph support and
   opposition witnesses both survive graph/table/fiber/JSON-LD export,
   and neither becomes unconditionally asserted RDF truth.
4. **No missing-source success:** absent Git corpus mount, missing original
   mathematical result, outdated gitlink or unqualified CAIRN source =>
   an explicit unavailable/unverified result, *not* a fallback to an old
   checkout or an empty public knowledge graph.
5. **No authorization-by-address:** copy an NI, focus URL or authorized JSON
   export to a second reader lacking grants. Re-query denies private
   source access; static downloads cannot be exchanged for new grants.
6. **No unsourced physical claims:** causal-set edge without a measured
   Lorentzian metric shows topology/order only; a conventional graph
   homology figure is not labeled a native generative theorem.
7. **Source-equivalent reader projections:** for one admitted article and
   claim revision, four Diátaxis routes retain exact source ID, claims,
   open obligations and proof-status matrix; route ordering differs only
   according to reader task, never source fact.
8. **Paper release truth:** a source draft with no editorial acceptance,
   qualified renderer, actual deployed article GET, independent readback
   or DOI remains an unreleased candidate even if repository CI is green.
9. **Graph accessibility:** keyboard focus moves from selected claim
   panel to transition evidence to exact source/next claim; no-JS and
   screen-reader/table views expose same source IDs, negative evidence
   and open questions.
10. **Bounded deterministic work:** native CAIRN q/predicate/focus/offset/limit
    determine the same authorized result before and after TUFTE renders it;
    invalid focus, unsupported filters and out-of-bounds pages are rejected
    without whole-chart fallback.

### Falsifiers

The design fails its core scientific requirement if it quietly turns
“a source was indexed” into “a generated kinematic point was proved,” if
diagrams erase counterevidence, if a conventional mathlib proof changes the
native conjecture's status, or if a public page is reachable only through
a private debug snapshot. Such errors are defects, not acceptable visual
trade-offs.

## 5. What will count as independent reception

Science accepts the **source contract** when the described claim identity
and status can be derived from actual Obsmetrologia carriers. Engineering
receives the *minimum interface delta* in existing CAIRN/TUFTE source (or
demonstrates it already exists), with source tests, installed dependencies
and bounded negative tests. Operations supplies actual package versions,
runtime grants, origin and TLS ingress. Editorial/public release uses one
Causeway-admitted publisher with licensed content and then obtains
an independent public GET of the source-matched page, its graphical
reader alternative, typed machine representation and refusal cases.

Until the whole chain receives, the outcome here is **a substantial
mathematical subject spec and authored teaching corpus in source control**,
not a public graph service. The owner's
[site README](README.md) and Causeway's
[estate registry](https://github.com/causeway-services/public-web-services-section/blob/main/sites/registry.json)
must continue to say so.
